# TechCompare 에이전트 스킬 운영 치트시트 (`skills-workflow.md`)

> `.cursorrules`의 `[Auto-Trigger Skill Routing]`에 의해 핵심 스킬 4종은 작업 요청 시 자동으로 작동합니다.

## 1. 작업 상황별 자동 적용 & 수동 호출 가이드

| 작업 상황 | 작동 방식 | 적용 스킬 | 사용자 입력(프롬프트) 예시 | 핵심 체크포인트 |
| :--- | :---: | :--- | :--- | :--- |
| **기능 추가 · 버그 수정 · 리팩터링** | **자동** | `ponytail` | *"비교함 초기화 버그 고쳐줘"* | 최소 Diff 수정, Zod 검증·에러 처리는 보존, 타협 시 `shortcut:` 기록 |
| **화면/컴포넌트 UI · 테마 스타일 수정** | **자동** | `design-taste-frontend` | *"상세 페이지 가격 표 여백 다듬어줘"* | 네온/글래스모피즘 배제, `tabular-nums` 정렬, 3종 블루 테마(`tokens.css`) 유지 |
| **로고 · 파비콘 · SVG 아이콘 제작/수정** | **명시 요청 시** | `logo-design` | *"헤더 로고 심볼 SVG로 다듬어줘"* | 명시 요청 시에만 작동 (일반 리팩터링 시 기존 로고·아이콘 변경 금지) |
| **기능 구현 완료 직후 · 커밋/PR 전** | **자동+호출** | `ponytail-review` | **`/ponytail-review`** 또는 *"방금 바꾼 거 리뷰해줘"* | 변경된 함수 호출부(Callers) 추적, 엣지 케이스·성능·불필요한 코드 점검 |
| **주 1회 또는 대규모 단계 완료 후** | **수동 호출** | `ponytail-audit` | **`/ponytail-audit`** 또는 *"전체 코드 감사해줘"* | 레포 전체 버그·보안 취약점·삭제 가능한 중복 코드 랭킹 리포트 |
| **`shortcut:` 주석이 쌓였을 때** | **수동 호출** | `ponytail-debt` | **`/ponytail-debt`** 또는 *"기술 부채 목록 보여줘"* | 코드 내 `shortcut:` 주석을 수집해 해결 우선순위 대장 출력 |

## 2. Ponytail 강도(Level) 조절 및 참고 명령어

| 명령어 | 역할 |
| :--- | :--- |
| `/ponytail lite` / `full`(기본) / `ultra` | 최소 변경 강도 전환 (`ultra`는 요청 자체의 필요성까지 역질문) |
| `/ponytail-gain` · `/ponytail-help` | *(참고용)* Ponytail 코드/토큰 절감 벤치마크 조회 및 명령어 요약 확인 |
